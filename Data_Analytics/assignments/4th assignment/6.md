2. Given a pandas DataFrame of Flipkart product reviews with columns: product_id, user_id, rating, review_text, identify and print the number of duplicate reviews (where product_id and user_id are both the same) before and after using drop_duplicates().

```python
import pandas as pd
reviews = pd.DataFrame({
    'product_id': [101, 101, 102, 103, 103, 104],
    'user_id':    [1, 1, 2, 3, 3, 4],
    'rating':     [4, 4, 5, 3, 3, 2],
    'review_text': ['Good', 'Good', 'Nice', 'Average', 'Average', 'Bad']
})
before = reviews.duplicated(subset=['product_id', 'user_id']).sum()
print('Duplicate reviews before drop_duplicates():', before)
reviews_clean = reviews.drop_duplicates(subset=['product_id', 'user_id'], keep='first')
after = reviews_clean.duplicated(subset=['product_id', 'user_id']).sum()
print('Duplicate reviews after drop_duplicates():', after)
print(reviews_clean)
```

3. Use the IQR method to detect outliers in the 'order_amount' column of a Zomato orders DataFrame and print the order IDs that are considered outliers.<br><br><em><strong>Hint:</strong> Calculate Q1, Q3, and IQR, then filter orders outside the [Q1 - 1.5*IQR, Q3 + 1.5*IQR] range.</em>

```python
import pandas as pd
orders = pd.DataFrame({
    'order_id': [1, 2, 3, 4, 5, 6, 7, 8],
    'order_amount': [200, 250, 260, 270, 275, 300, 5000, 320]
})
Q1 = orders['order_amount'].quantile(0.25)
Q3 = orders['order_amount'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
outliers = orders[(orders['order_amount'] < lower_bound) | (orders['order_amount'] > upper_bound)]
print('Outlier order IDs:')
print(outliers['order_id'].tolist())
```

4. For a DataFrame containing daily IPL match ticket sales (columns: date, tickets_sold), calculate the Z-score for each day's tickets_sold, and print the dates where the absolute Z-score is greater than 2.<br><br><em><strong>Constraint:</strong> Use pandas and scipy.stats.zscore for calculations.</em>

```python
import pandas as pd
from scipy.stats import zscore
ipl_sales = pd.DataFrame({
    'date': ['2024-01-01', '2024-01-02', '2024-01-03', '2024-01-04', '2024-01-05'],
    'tickets_sold': [1200, 1300, 1250, 1100, 5000]
})
ipl_sales['z_score'] = zscore(ipl_sales['tickets_sold'])
outlier_dates = ipl_sales[abs(ipl_sales['z_score']) > 2]['date']
print('Dates with extreme ticket sales:')
print(outlier_dates.tolist())
```

5. Use ChatGPT or Copilot to generate a pandas function that finds and returns all outlier transaction amounts in a Paytm wallet DataFrame using the Z-score method, then test the function with sample data.

```python
import pandas as pd
from scipy.stats import zscore
def find_outlier_transactions(df):
    """Return rows where transaction_amount has abs(Z-score) > 2."""
    if 'transaction_amount' not in df.columns:
        raise ValueError("DataFrame must contain 'transaction_amount' column")
    z_scores = zscore(df['transaction_amount'])
    outliers = df[abs(z_scores) > 2].copy()
    return outliers

paytm_df = pd.DataFrame({
    'transaction_id': [101, 102, 103, 104, 105, 106],
    'transaction_amount': [200, 210, 205, 215, 220, 5000]
})
outlier_rows = find_outlier_transactions(paytm_df)
print('Outlier transactions:')
print(outlier_rows)
```
