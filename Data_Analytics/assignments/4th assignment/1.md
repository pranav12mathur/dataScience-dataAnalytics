3. Given a list of follower counts for 5 Instagram influencers: [1200, 54000, 780, 150000, 32000], create a pandas Series called 'followers', then print the influencer(s) with the highest and lowest follower counts.<br><br><em><strong>Hint:</strong> Use Series.idxmax() and Series.idxmin() to find the indices.</em>

```python
import pandas as pd

influencers = ["Aanya", "Rohit", "Meera", "Kabir", "Ishita"]
follower_counts = [1200, 54000, 780, 150000, 32000]

followers = pd.Series(follower_counts, index=influencers)

print("Highest followers:", followers.idxmax(), followers[followers.idxmax()])
print("Lowest followers:", followers.idxmin(), followers[followers.idxmin()])
```
