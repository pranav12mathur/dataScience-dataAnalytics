# What is URL?

A URL (Uniform Resource Locator) is the address used to locate and access resources on the internet, such as web pages, files, images, or services. A URL usually includes a protocol, domain name, path, and optionally a port, query string, and fragment.

# Types of URL

Common types of URLs are based on the protocol or scheme:

- `http://` – HyperText Transfer Protocol
- `https://` – Secure HTTP
- `ftp://` – File Transfer Protocol
- `ftps://` – Secure FTP
- `file://` – Local file access
- `data:` – Inline data encoded in the URL
- `mailto:` – Email address link
- `tel:` – Telephone number link
- `ws://` – WebSocket protocol
- `wss://` – Secure WebSocket protocol
- `urn:` – Uniform Resource Name
- `ldap://` – LDAP directory access

These are the main URL types commonly used on the web and in applications.
