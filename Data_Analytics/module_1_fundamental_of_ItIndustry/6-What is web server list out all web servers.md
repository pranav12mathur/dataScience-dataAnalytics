# What is a Web Server?

A web server is software and hardware that delivers web pages and web applications to users over the internet or an intranet. It processes incoming requests from clients (usually web browsers), retrieves the requested content, and sends the response back to the client using the HTTP or HTTPS protocol.

# Key Functions of a Web Server

- Accepts and handles HTTP requests
- Serves static files like HTML, CSS, JavaScript, and images
- Executes server-side applications or scripts when needed
- Sends HTTP responses back to the client
- Manages connections and resources
