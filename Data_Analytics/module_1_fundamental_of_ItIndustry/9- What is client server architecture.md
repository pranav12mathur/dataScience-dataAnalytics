# Client-Server Architecture

Client-server architecture is a distributed computing model that separates tasks between clients and servers.

- Client: sends requests for services or resources.
- Server: listens for requests, processes them, and returns responses.

Key characteristics:

- Separation of roles between client and server.
- Communication happens over a network.
- The server provides centralized services, while clients consume them.
- It supports scalability by allowing multiple clients to connect to one or more servers.

Common example:

- A web browser (client) requests web pages from a web server.
