# What is WWW (World Wide Web)?

## Definition
The **World Wide Web (WWW)** is a system of interconnected hypertext documents and resources linked by hyperlinks and accessed through the Internet using a web browser.

## Key Characteristics

- **Hypertext**: Documents contain links to other documents
- **Global**: Accessible from anywhere with an internet connection
- **Client-Server Architecture**: Uses HTTP/HTTPS protocol
- **User-Friendly**: Accessible through graphical web browsers

## History
- Invented by **Tim Berners-Lee** in 1989 at CERN
- First web page published in 1991
- Revolutionized information sharing and communication

## Components

### 1. **URL (Uniform Resource Locator)**
- The web address (e.g., https://www.example.com)

### 2. **HTTP/HTTPS (Protocol)**
- HyperText Transfer Protocol (Secure)
- Rules for data transmission

### 3. **Web Browsers**
- Software to view web pages (Chrome, Firefox, Safari, Edge)

### 4. **Web Servers**
- Host and serve web content

## How WWW Works

1. User enters URL in browser
2. Browser sends request to web server
3. Server processes request and sends data
4. Browser receives and renders the page
5. User views the content

## Difference: Internet vs WWW

| Feature | Internet | WWW |
|---------|----------|-----|
| Scope | Global network infrastructure | Application/Service on Internet |
| Started | 1960s (ARPANET) | 1989 |
| Protocol | Multiple (TCP/IP, etc.) | HTTP/HTTPS |
| Purpose | Data communication | Information sharing |

## Importance
- Transformed how we communicate and share information
- Foundation of modern digital economy
- Enables e-commerce, social media, and remote work
