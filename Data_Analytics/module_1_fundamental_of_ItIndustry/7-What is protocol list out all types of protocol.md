# What is protocol?
1. A protocol is a standardized set of rules and guidelines that governs how data is transmitted, received, and interpreted
   
# list out all types of protocol?
1. Network Communication Protocols
   **examples**
   TCP, UDP, HTTP, HTTPS, FTP
2. Network Management Protocols
   **examples**
   SNMP, DHCP, ICMP
3. Network Security Protocols
   **examples**
   SSL, TLS, IPSec, SSH
4. Routing Protocols
   **examples**
   RIP, OSPF, BGP, EIGRP
5. File Transfer Protocols
   **examples**
    FTP, SFTP, TFTP
6. Email Protocols
   **examples**
   SMTP, POP3, IMAP
7. Remote Access Protocols
   **examples**
   Telnet, SSH, RDP
8. Wireless Communication Protocols
   **examples**
   Wi-Fi, Bluetooth, Zigbee, NFC
